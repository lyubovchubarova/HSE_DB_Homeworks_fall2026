# Домашнее задание 4 — аналитическая витрина в ClickHouse

Небольшой учебный проект на данных вакансий «Работы России». Одни и те же
59 795 вакансий загружаются в PostgreSQL и в две таблицы ClickHouse с разным
порядком сортировки. Новая пачка из Рязанской, Орловской и Магаданской областей
добавляется отдельно, чтобы проверить incremental materialized view.

## Быстрый запуск

Нужны Python 3.11+, Docker и `docker-compose`.

```bash
make all
```

Команда установит Python-зависимости, запустит тесты и контейнеры, загрузит
данные, проверит равенство, выполнит benchmark и нарисует evidence. Первый
запуск может быть дольше из-за скачивания Docker-образов; повторный обычно
занимает несколько минут.

Основные отдельные команды:

```bash
make test          # unit-тесты
make up            # запустить PostgreSQL и ClickHouse
make prepare       # пересоздать схему и загрузить две пачки
make verify        # полная сверка данных и двух запросов
make benchmark     # прогрев + 5 замеров каждого запроса
make render        # четыре PNG с evidence
make stop          # остановить контейнеры, сохранив volumes
make destroy       # удалить только контейнеры и volumes этого проекта
```

Новая пачка уже лежит в `data/vacancies_new_batch.csv`. При необходимости её
можно заново скачать командой `make download-new`, но API является живым, и
число вакансий изменится.

Все пути вычисляются относительно `$(CURDIR)`: абсолютных путей к этому
компьютеру в проекте нет. На macOS с Colima Makefile сам использует стандартный
socket Colima, если он существует; с Docker Desktop используется обычный
default socket. Проект использует отдельный пустой `DOCKER_CONFIG`, чтобы не
зависеть от локальных credential helpers и пользовательских контекстов.

Результаты находятся в `evidence/`, описание эксперимента — в `REPORT.md`.
